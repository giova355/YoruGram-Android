# Правила разработки YoruGram

YoruGram — независимый клиент, использующий Telegram API. Название и графика принадлежат проекту. Пользовательские условия Telegram и правила для разработчиков API действуют отдельно. Условия распространения исходников кода определены лицензиями соответствующих репозиториев.

Перед выпуском указывайте использование Telegram API в описании приложения и во вводной информации внутри клиента. Для выпуска и входа с аккаунтами проекта требуется собственный API ID. Публичные тестовые параметры Telegram разрешены в рамках заявленного тестового назначения.

Совместимость предполагает корректное отображение прочтения, времени последней активности и набора текста, соблюдение автоудаления и показ официальных спонсируемых сообщений в каналах. Запросы с последствиями для пользователя требуют его согласия. Файлы и сообщения, отправленные из YoruGram, должны открываться в официальных клиентах. YoruGram не собирает данные Telegram для обучения моделей.

Yoru Connect — отдельная услуга управляемого подключения. Она не изменяет Telegram Premium, права на контент или правила API. При выпуске раскрывайте в описании клиента все активные способы монетизации, пользование пробным периодом и условия оплаты. Перед публичным запуском VPN в России проверьте регуляторные требования к услуге, рекламе и обработке данных.

- [Условия Telegram для пользователей](https://telegram.org/tos)
- [Условия Telegram для разработчиков API](https://core.telegram.org/api/terms)
- [Регистрация API ID и тестовый режим](https://core.telegram.org/api/obtaining_api_id)
